# 点阵畸变矫正工具

这是一个基于 `.NET 8 + WinForms + OpenCvSharp4` 的图像矫正程序，适用于 HUD/投影系统中由镜头、曲面镜、挡风玻璃和装配姿态共同产生的非对称畸变。

## 使用方法

1. 在 Visual Studio 2022/2025 中打开 `DistortionCorrectionApp.csproj`。
2. 选择“拍摄图像”：图 1 的相机拍摄结果。
3. 选择“原始基准图”：图 2 的未预畸变图卡。
4. 确认点阵为 `27` 列、`7` 行，点击“拟合映射并矫正”。
5. 程序会在拍摄图中检测亮点中心，在原始图中检测对应点，按行列顺序建立对应关系，并把拍摄图重采样到原始图尺寸。

程序同时输出两张图：拍摄图文件名加 `_corrected.png` 的“拍摄矫正图”，以及基准图文件名加 `_predistorted.png` 的“投影预畸变图”。前者用于把相机拍摄结果拉回正常形状，后者用于重新投影到同一光学系统，使再次拍摄后的点阵接近原始基准图。程序还会保存 `_corrected_warp.json` 映射模型。

## 参数建议

- 默认阈值为 `30`。如果检测不到 189 个点，降低阈值；如果把背景噪声也检测出来，提高阈值。
- 点面积默认范围为 `2–500 px²`。点较大或较小时调整此范围。
- 程序使用 27×7 局部双线性网格映射，逐格拟合点阵之间的局部畸变，适合非对称和自由曲面光学系统。
- 如果图像亮度分布不稳定，可以勾选 `使用 Otsu 自动阈值`。

## 重要说明

这个程序不是只根据一张照片猜测畸变，而是用“拍摄点阵”和“原始点阵”的实际对应点拟合映射。因此，标定图必须和后续待矫正图保持同一投影分辨率、光学路径、相机位置、焦距和对焦状态。若更换相机位置、镜头、投影图像尺寸或光学组件，需要重新采集点阵并重新拟合。

输出图像的有效内容由拍摄图决定。由于示例中拍摄点阵集中在画面中部，矫正到全屏后，点阵以外没有被相机拍到的区域无法凭空恢复，程序会以黑色填充无效区域。
